# JavaScript Interactive Website

A professional JavaScript interactive website built from scratch without any frameworks.

## Project Structure

This project follows a clean, modular structure.

```text
javascript-interactive-website/
│
├── index.html        # Main HTML document
├── css/
│   └── style.css     # Modular, variable-driven CSS
├── js/
│   └── script.js     # JavaScript broken down into modular functions
├── assets/
│   ├── images/       # Project images
│   └── icons/        # Project icons (SVG, PNG, etc.)
├── README.md         # Project documentation
└── LICENSE           # License information
```

## Technologies Used

- **HTML5:** Semantic markup
- **CSS3:** Custom properties (variables), Flexbox/Grid, Mobile-first design
- **Vanilla JavaScript:** DOM manipulation, Event handling, IntersectionObserver

## How to Run

1. Clone the repository.
2. Open `index.html` in your favorite browser. No build steps required.
